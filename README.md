# Chesed raffle screen

Hallway screen for the Al Shelosha Devarim Chesed raffle at Moriah. Shown on Yodeck as a Web Page.

All names, tickets, prizes and wording come from the Google Sheet "Chesed Raffle Screen" (tabs Tickets, Prizes, Settings). The page re-reads it every 5 minutes. Student names are never stored in this repo.
